# Security Policy

This policy applies to all public repositories of GifariKemal / PT Surya Inovasi Prioritas (SURIOTA) that do not ship their own `SECURITY.md`.

## Reporting a vulnerability

Please report security issues **privately** through GitHub:

1. Open the affected repository.
2. Go to the **Security** tab and click **Report a vulnerability**.
3. Describe the issue, affected files or versions, and steps to reproduce.

Please do **not** open a public issue, pull request, or discussion for security problems.

If you find an exposed credential (API key, token, password), report it the same way. Do not use it, and do not share it.

## Guidelines

- Test only against your own setup or data. Do not access, modify, or delete data that is not yours.
- Avoid actions that could degrade services or affect other users.
- Give us reasonable time to fix the issue before any public disclosure.

## Supported versions

Only the latest commit on the default branch of each repository is supported. Many repositories here are experiments, proof-of-concepts, or archives and may not receive fixes.
